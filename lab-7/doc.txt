Leaders

First statement in main() (menu loop start).

Each case block inside switch.

Each function (addStudent, displayStudents, etc.) starts a new CFG.

For main(), leaders are:

B0: Start, menu print.

B1: switch(choice).

B2: case 1 → addStudent().

B3: case 2 → displayStudents().

B4: case 3 → searchStudent().

B5: case 4 → updateMarks().

B6: case 5 → deleteStudent().

B7: case 6 → exit.

B8: default case.

B0: print menu, scanf(choice)
B1: switch(choice)
B2: case 1 → addStudent()
B3: case 2 → displayStudents()
B4: case 3 → searchStudent()
B5: case 4 → updateMarks()
B6: case 5 → deleteStudent()
B7: case 6 → exit
B8: default → "Invalid choice!"

CFG Edges

Sequential: B0 → B1.

Switch branches:

B1 → B2

B1 → B3

B1 → B4

B1 → B5

B1 → B6

B1 → B7

B1 → B8

After each case (except exit): edges back to B0 (menu loop).
